# Big Data Sales Analytics

## Project Overview
This project analyzes sales data using Python and Apache Spark (PySpark). It demonstrates data ingestion, data cleaning, transformation, aggregation, and visualization.

## Technologies
- Python
- Apache Spark (PySpark)
- Hadoop HDFS (planned integration)
- Pandas
- Matplotlib
- Google Colab

## Project Pipeline
1. Data ingestion from CSV.
2. Data cleaning and preprocessing.
3. Sales revenue calculation.
4. Analysis by product and region.
5. Data storage using Parquet.
6. Data visualization.

## How to Run
1. Open the notebook in Google Colab.
2. Install PySpark.
3. Run the notebook cells in order.
